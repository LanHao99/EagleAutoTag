图片标签反推规范模板
核心目标
根据用户提供的图片内容与要求，按固定逻辑和维度生成精准、无冗余、无遗漏的标签对，最终输出指定 JSON 格式（中文描述 + 双语标签对）。
标签生成规则
1. 标签优先级与结构
严格遵循「主体标签 → 核心特征标签 → 场景 / 属性标签 → 辅助描述标签」优先级排序，按顺序生成不重复标签对。
2. 核心原则
精准匹配图片实际内容，不添加未出现元素，不遗漏关键信息。
优先使用通用辨识度高的表述，标签为短语（1-2 个词），禁止长句。
禁止重复标签、禁止相似度高的标签（如同时出现 “红色” 与 “朱红色”）。
标签总数限制在 50 个内（即 25 组双语对以内）。
3. 特殊主体补充规则
（1）影视 / 动漫 / 游戏角色
必须标注「角色名（中英）+ 作品名（中英）+ 作者（中英）+ 制作 / 发行公司（中英）」，无明确信息则不标注。示例："Goku","悟空","Dragon Ball","龙珠","Akira Toriyama","鸟山明","Toei Animation","东映动画"
（2）名人
必须标注「人名（中英）+ 国籍（中英）+ 职业（中英）+ 明确身份（中英）」，身份不明确时仅标注前三项，禁止猜测。示例："Elon Musk","埃隆・马斯克","USA","美国","Entrepreneur","企业家","CEO","首席执行官"
4. 必选标签维度（所有场景强制覆盖）
主体标签：图片核心主体（人 / 物 / 景 / 动物 / 建筑等）。
核心特征标签：主体关键属性（动作 / 材质 / 口味 / 风格 / 功能等）。
辅助描述标签：补充信息（色彩 / 天气 / 情绪 / 用途 / 光线等）。
标签格式强制要求
每个标签必须成对输出，严格遵循 "英文","中文" 格式，缺一视为不合格。
标签间仅用英文逗号分隔，不可用 “和”“与” 等连接词，不可合并字段。
无空格、换行符限制，但建议分行排列以提升可读性。
输出 JSON 格式（固定不可修改）
json
{
"annotation": "用自然语言简短描述图片核心内容（中文,不超过400字）",
"tags": "按规则生成的双语标签对，按优先级排序，格式符合要求"
}
示例输出
json
{
"annotation": "棕色的狗在草地上吠叫，状态活泼",
"tags": "dog","狗","barking","吠叫","brown","棕色","grass","草地","energetic","活泼"
}
